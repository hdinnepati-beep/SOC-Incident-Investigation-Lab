# SOC Incident Investigation Lab

## Project Overview

This project demonstrates my SOC investigation methodology using simulated security incident scenarios.

The project focuses on alert triage, phishing investigation, brute-force attack investigation, malware investigation, IOC analysis, incident response, and MITRE ATT&CK mapping.

## Skills Demonstrated

* Security Alert Triage
* Log Analysis
* Incident Investigation
* Phishing Analysis
* Malware Investigation
* IOC Analysis
* Incident Response
* MITRE ATT&CK Mapping
* Windows Event Log Analysis

## Project Scenarios

### 1. Alert Triage

Investigation and validation of security alerts.

### 2. Phishing Investigation

Analysis of suspicious emails, URLs, email headers, and extracted indicators.

### 3. Brute Force Investigation

Analysis of multiple failed login attempts followed by successful authentication.

### 4. Malware Investigation

Investigation of a simulated malware detection alert.

### 5. IOC Analysis

Analysis of suspicious IP addresses, domains, URLs, and file hashes.

## Investigation Process

1. Alert Validation
2. Log Analysis
3. Investigation
4. IOC Identification
5. Incident Classification
6. MITRE ATT&CK Mapping
7. Containment Recommendation
8. Escalation
9. Incident Documentation

## Disclaimer

All incidents, logs, usernames, IP addresses, domains, and other indicators used in this project are simulated and created only for educational purposes.
