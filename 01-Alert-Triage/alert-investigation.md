# Security Alert Triage

## Scenario

A security alert was generated for suspicious login activity.

The alert was investigated to determine whether the activity was legitimate or required further escalation.

## Alert Validation

The following details were reviewed:

* Alert Name
* Alert Severity
* Username
* Source IP Address
* Destination System
* Timestamp
* Related Events

## Investigation Process

### Step 1: Review the Alert

The alert details were reviewed to understand the reason for the alert generation.

### Step 2: Validate the User Activity

The username and login activity were reviewed to determine whether the login behavior was expected.

### Step 3: Analyze the Source IP

The source IP address was checked for unusual or suspicious activity.

### Step 4: Review Related Events

Related authentication events were reviewed to identify multiple failed login attempts or unusual login patterns.

### Step 5: Incident Classification

Based on the investigation findings, the alert was classified as:

* True Positive
* False Positive
* Benign Activity

## Escalation

If suspicious activity is confirmed, the incident should be escalated according to the defined SOC escalation procedure.

## Conclusion

Alert triage helps SOC analysts validate security alerts and prioritize incidents that require immediate investigation.
